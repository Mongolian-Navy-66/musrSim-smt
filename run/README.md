# Historical run material / 历史运行资料

**English:** Most macros and shell scripts in this directory were inherited from musrSim-jp/SMS/PSI. Some contain obsolete absolute paths and target geometries unrelated to muon scattering tomography. They are retained for provenance and are not a ready-to-run validation of `truthPlaneZ`. Use the companion `muography_shine` sim4/sim5 macros, or adapt your own geometry and insert `truthPlaneZ` before `/run/beamOn`.

**中文：**本目录的大多数宏和脚本来自 musrSim-jp/SMS/PSI，部分含过期绝对路径或与 muon 散射层析无关的几何。保留它们用于追溯，但它们不是 `truthPlaneZ` 的现成验收宏。请使用配套 `muography_shine` 的 sim4/sim5 宏，或按自己的几何修改并在 `/run/beamOn` 前加入 `truthPlaneZ`。
